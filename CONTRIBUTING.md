# Contributing

## A swap was frozen, or you were asked for ID

Open an issue with the service, the date, what you were asked for and how it ended. Remove personal details first; a transaction ID or a support chat screenshot helps.

## Add a service

Open an issue with links to the service and to its terms. It qualifies when it swaps crypto to crypto without an account and has been running for at least six months.

## Correct the data

Edit `data/services.yml` and open a pull request with a link that backs the change: a clause in the terms, an announcement, a public report.
